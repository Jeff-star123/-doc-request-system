About Barangay Bulsa-Korapot Document Request System

The Barangay Bulsa-Korapot Document Request System is a digital platform designed to automate the process of requesting local documents like Barangay Clearances and Certificates of Residency remotely. Developed strictly as a school project requirement and presentation prototype for our BSIT program.

Online Application

Remote document request system...

Enables residents to request Barangay Clearances, Certificates of Residency, and Indigency remotely without physical queuing.

24/7 Access
