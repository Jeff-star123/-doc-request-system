About Barangay Bulsa-Korapot Document Request System

The Barangay Bulsa-Korapot Document Request System is a digital platform designed to automate the process of requesting local documents like Barangay Clearances and Certificates of Residency without the need for in-person queuing. Crucially, this system was developed strictly as a school project requirement and presentation prototype for our BSIT program, and it is not an officially deployed government application.

Secure Online Portal
Provides residents with a remote way to request necessary barangay documents, eliminating physical lines at the barangay hall.
Advanced Verification
Features a multi-step security process, including ID submission and biometric liveness face scanning alongside account restrictions for misuse.
Automated Communication
Integrates automated Telegram alerts for status updates and features a Dify-powered AI chatbot to handle user inquiries.
Administrative Controls
Equips barangay officials with tools to manage incoming document requests, track transaction histories, and update user statuses.
Modern UI
Utilizes a dark-mode interface designed for improved accessibility, smoothness, and intuitive user experience.
