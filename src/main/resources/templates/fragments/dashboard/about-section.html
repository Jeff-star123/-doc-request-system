Online Application

Remote document request system...

Enables residents to request Barangay Clearances, Certificates of Residency, and Certificates of Indigency remotely with automated PDF printing upon approval.

24/7 Access
Tesseract OCR Reader

Automated client-side ID reading...

Integrates Tesseract.js directly inside the client browser to automatically verify uploaded IDs (National ID, Student ID, Driver's License, UMID, Barangay ID).

Client-Side AI
3D Biometric Face Scan

3D Real-time face tracking...

Powered by MediaPipe FaceMesh for real-time 3D head landmark tracking. Enforces a 3-step gesture scan (Straight, Turn Left, Turn Right) to prevent proxy fraud.

MediaPipe AI
Telegram Alerts & Bot

Instant OTP & status updates...

Dispatches automated real-time status alerts (Approved/Rejected) and 6-digit verification OTP codes directly to residents' Telegram accounts via @BrgyDocRequestBot.

Real-time Push
Bilingual AI Assistant

Bilingual Tagalog/English chatbot...

An embedded bilingual chatbot designed to answer resident questions regarding clearance requirements, face scan steps, Telegram setup, and tracking.

Admin Command Console

Verification review & user controls...

Equips barangay officials with verification inspection tools, approval/rejection decision workflows, and pending account reactivation management.

Admin Console
Admin Spotify Player

iTunes JSONP live music stream...

Features a Spotify-inspired media player embedded in the Admin Console. Uses Apple iTunes JSONP API for real-time track searching, album cover rendering, and 30s audio streaming without CORS blocking.

iTunes API
In-App API Gateway

Rate limiting & IP proxy awareness...

Interceptors running on /api/** routes enforce client rate limiting (10 req/min), header normalization (X-API-Gateway), and X-Forwarded-For proxy IP resolution.

Gateway Filter
Anti-Spam Safeguards

Click tracking & auto-deactivation...

Tracks rapid document print attempts. Displays countdown warnings on 4 clicks and triggers automatic account deactivation with archival logging on 5 clicks.

Spam Lock
Secure Uploads & Privacy

Authenticated file serving & anti-cache...

Serves uploaded ID and selfie proof files through authenticated endpoints with HTTP anti-caching headers (no-store, no-cache) to prevent intermediate CDN caching.
